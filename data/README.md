# Data directory

Place manufacturing workbooks here for automatic discovery, or upload files through the Streamlit sidebar.

## Bundled sample (synthetic)

| File | Notes |
|------|-------|
| `sample_manufacturing_records.xlsx` | Demo workbook with sheets `Manufacturing Records` and `Alternate Schema` |
| `sample_manufacturing_records.csv` | CSV export of the main sheet |

These files are **synthetic** demo data for Level 1 testing. They are not real production manufacturing records.

Example part numbers on the main sheet: `2280`, `2281`, `00123`, `123`, `4500`, `9901` (duplicate rows).
